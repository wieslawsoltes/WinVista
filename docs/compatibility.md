# Compatibility and implemented scope

The visual target is Windows Vista Ultimate SP1 at 96 DPI, using Aero glass and the Vista taskbar model: a Start orb, separate Quick Launch area and labeled application buttons. Authentic archived wallpaper, icon frames and sounds are included with provenance in `assets-manifest.json` and `sound-sources.json`.

This is an independent browser desktop recreation, not Windows Vista, a Windows kernel, a virtual machine or a Win32 compatibility layer. It does not satisfy literal “all OS features, all original applications, pixel-perfect parity.” The following matrix records the concrete implementation.

## Games

Minesweeper, Klondike Solitaire, FreeCell, Spider Solitaire, Hearts, Chess Titans, Mahjong Titans, Purble Place and InkBall contain playable rules. They are independent implementations with simplified artwork and layouts. Chess and Mahjong do not reproduce the original Direct3D scenes. Purble Place provides memory, cake-order and deduction games; InkBall uses a 2D physics implementation rather than the original engine. Game options, statistics and difficulty are subsets of the originals.

Chess includes legal moves, castling, en passant, promotion, check/mate, stalemate, basic insufficient material, threefold repetition, fifty-move handling, undo and a worker-based opponent. It does not implement tournament clock/claim procedures or every possible dead-position adjudication. Solitaire-family engines support card movement, stock rules, foundations/completed runs, undo and hints. See tests for the specific verified invariants.

## Graphics and browser boundaries

WebGPU is used for the desktop wallpaper and compute filters. WebGL2 and Canvas 2D provide fallback wallpaper paths; the CPU implements the same filter arithmetic. App controls, text and most windows are HTML/CSS. Real hardware GPU execution was not verified in the build environment.

Files and settings are scoped to the current browser profile and origin. Private browsing, storage clearing, blocked storage or quotas can prevent persistence. Use Backup and Restore to make an explicit export. No server backup or cross-device synchronization is provided.

Original Segoe UI is used when installed; otherwise the font stack falls back to Tahoma/Arial. Text metrics, antialiasing, browser control rendering, DPI and zoom can change pixels. **No screenshot-diff certification or pixel-perfect claim is made.** The available preview browser could not reach the internal preview during this build.
